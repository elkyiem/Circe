## Fixed

- The library window goes full screen from the green button, the View menu, or Control-Command-F.
- Fish on a Codex subscription can pick any model Codex lists, not only Default.
- Fish on a Claude Code subscription can pick Opus, Sonnet, or Haiku, not only Default.
